# Минимальные фикстуры карточек Авито

Три небольшие, вручную составленные HTML-фикстуры имитируют только форму
структурированного состояния карточки: вторичная квартира, новостройка и дом.
Фактические значения перенесены из предоставленных владелицей снимков, но
исходная разметка, текст объявления, продавец, контакты, медиа и служебные
идентификаторы не сохраняются.

| Файл | Тип | Канонический URL |
|---|---|---|
| `avito-secondary-8437781969.html` | вторичная квартира | `https://www.avito.ru/tula/kvartiry/2-k._kvartira_473_m_716_et._8437781969` |
| `avito-newbuilding-8083315215.html` | новостройка | `https://www.avito.ru/tula/kvartiry/2-k._kvartira_1019_m_17_et._8083315215` |
| `avito-house-8093402924.html` | дом | `https://www.avito.ru/tula/doma_dachi_kottedzhi/dom_128_m_na_uchastke_8_sot._8093402924` |

Фикстуры детерминированы и используются только offline. Они не доказывают
право на автоматические запросы. `robots.txt` также не является разрешением.
Live HTTP остаётся заблокирован Source Policy до независимого подтверждения
доступа и использования нормализованных данных.

## Риск истории Git

В раннем commit этой feature-ветки находились полные браузерные снимки с
персональными и служебными данными. Текущая версия их не содержит, однако Git
history продолжает хранить прежние blobs. Очистка опубликованной истории —
отдельное решение владельца репозитория; до него ветку нельзя считать
подходящей для публичного распространения только на основании этого cleanup.
