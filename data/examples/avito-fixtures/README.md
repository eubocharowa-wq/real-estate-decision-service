# Фикстуры карточек Авито (для адаптера источника)

Три сохранённые карточки объявлений по Туле, по одной на каждый тип
рынка. Сохранены владелицей проекта из браузера 11 ноября 2026, затем
очищены: удалены все скрипты, КРОМЕ блока с данными объявления
(экранированный JSON с `\"item\":{...}` — адрес, цена, координаты);
имя продавца затёрто («[продавец скрыт]»); телефонов в карточках Авито
нет изначально (они скрыты за кнопкой). Факты не изменялись.
Оставшиеся в файлах цифровые последовательности, похожие на телефоны, —
случайные совпадения в служебных именах CSS-классов.

Где лежат факты:
- встроенный экранированный JSON (`\"item\":{...,\"address\":...,
  \"geo\":{\"coords\":...}}`, цена в `\"price\":{...\"value\":N}`) —
  основной источник;
- продублировано в видимой разметке: `data-marker="item-view/item-price"`,
  `data-marker="item-view/item-params"` (комнаты, площади, этаж,
  материал стен, участок), `<link rel="canonical">`;
- тип рынка: хлебные крошки (`vtorichka` / `novostroyka` в itemid)
  и категория в URL (`/kvartiry/` против `/doma_dachi_kottedzhi/`);
  у новостройки от застройщика в данных есть название ЖК.

## Решение владелицы (зафиксировано 11 ноября 2026)

Источник Авито включён решением владелицы проекта. Рамки:
- только отдельные карточки по каноническим URL без query-параметров;
  поисковые и фильтрованные страницы не запрашиваются (их же
  `robots.txt` запрещает адреса с параметрами — копия файла рядом:
  `robots-2026-11-11.txt`, раздел `User-agent: *`);
- честное представление клиента, низкая частота запросов, кэш;
- при 403/429/капче сбор останавливается, обход блокировок запрещён;
- извлекаются только факты; текст объявления, фотографии, телефоны и
  данные продавца не извлекаются и не воспроизводятся;
- все значения — «заявлено продавцом» (claimed), только в staging,
  не в canonical.

Это снимки на дату сохранения: цены и статусы могли измениться.
