# Минимальные фикстуры карточек ЦИАН

Три небольшие, вручную составленные HTML-фикстуры имитируют только
`frontend-offer-card/defaultState`, который читает parser: новостройка,
вторичная квартира и дом. Разрешённые факты перенесены из предоставленных
владелицей снимков. Исходная страница, текст объявления, контакты, данные
продавца/агента, медиа и служебные конфиги не сохраняются.

Фикстуры используются только offline. Они не подтверждают право на
автоматический доступ: live HTTP остаётся заблокирован Source Policy, пока не
подтверждены и доступ, и допустимое использование нормализованных данных.

## Риск истории Git

PR #23 и ранняя история этой ветки содержали значительно более полные снимки.
Текущие файлы очищены, но прежние blobs остаются в Git history. Возможная
перезапись опубликованной истории — отдельное решение владельца репозитория.
