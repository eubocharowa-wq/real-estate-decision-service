Три сохранённые карточки объявлений, по одной на каждый тип рынка.
Сохранены владелицей проекта из браузера без входа в аккаунт
(10–11 ноября 2026), затем урезаны до встроенного state-скрипта
`window._cianConfig['frontend-offer-card']`; телефоны продавцов и
агентов затёрты (`0000000000`). Факты (цена, площадь, этаж, адрес,
тип рынка) не изменялись.

Назначение: разработка и тесты адаптера карточек Циан без обращения
к живому сайту. Это снимки на дату сохранения: цены и статусы могли
измениться — данные из них подаются только как «заявлено продавцом»
(claimed) и только в staging, не в canonical.

Юридические рамки (решение владелицы): берём только факты; текст
объявления и фотографии не воспроизводим; сбор — только отдельные
карточки по каноническим URL без query-параметров, с честным
представлением клиента, лимитом частоты и остановкой при 403/429
или капче.
